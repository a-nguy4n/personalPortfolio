# Project Enhancements  

## Enhancements Made  
- Improved UI/UX for project cards  
- Added animations 
- Ensured better mobile responsiveness  
- Optimized JavaScript to dynamically load content:  
  - Dynamic navigation menu:  
    - Different color for each page  
    - Remembers the last visited page  
    - Tracks navigation history:  
      - Stores the "From" (previous page) and "To" (current page) values  
      - Upon returning to the site or refreshing, the menu reads this stored data and highlights the last active section  
    - Maintains theme consistency
